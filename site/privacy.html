Privacy, in plain English.

Leftover looks through your disk, so you should know exactly what it does there. The short version: it runs on your computer, it never sends anything anywhere, and it only changes what you tell it to.

The app

What it collects

Nothing. Leftover has no account, no analytics, no crash reporting and no update checks. It contains no networking code that talks to the internet, and it works the same with the network unplugged.

What it reads

To find caches, Leftover reads folder listings and file sizes in your home folder and in the places tools are documented to keep their data. It does not open or read the contents of your files, with three small exceptions it needs to explain what it found: a Python environment's pyvenv.cfg (to see if its Python still exists), Ollama's model manifests (to list your models), and the names of files next to a folder (to tell a Node.js node_modules from any other folder of that name).

If Docker is installed, Leftover runs docker system df on your machine to show what is inside Docker's disk image. That command only reads, and its output stays on your computer.

What it writes

Scanning only reads. Leftover writes to a single folder of its own: settings, the result of the last scan, a history log, and the vault. Run leftover where to see where it is on your machine.

Outside that folder, the only changes are the ones you confirm: moving an item you picked into the vault, putting one back, or emptying the vault. Moving into the vault is a rename on the same drive, so nothing is copied and nothing is deleted. Items stay restorable for 14 days unless you change that. Every move, restore and deletion is written to the history log, which you can read in the app or with leftover history.

The window

The app's window is a page served by Leftover itself to your computer only, on a private address (127.0.0.1) with a random key that changes every launch. Other websites can't reach it. When it opens in Chrome, Edge or Brave, it uses a separate profile with syncing, update checks and other background requests switched off.

Checking for yourself

Leftover is open source under the MIT license and uses nothing beyond Go's standard library, so the whole program is short enough to read. The code is on GitHub, and every release lists checksums so you can verify what you downloaded.

This website

This site is a few static files. It sets no cookies, runs no analytics, embeds nothing from other companies and loads no fonts, scripts or images from anywhere else. The only script animates the page.

Like any website, the service that hosts these files may keep ordinary server logs, such as IP addresses and the pages requested, for security and operations. Downloads are served by GitHub, under GitHub's privacy statement. We don't receive or look at personal data from either.

Questions

If anything here is unclear, or you find Leftover doing something this page doesn't describe, please open an issue. That would be a bug, and it will be treated as one.
